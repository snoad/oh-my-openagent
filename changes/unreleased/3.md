### Added

- **OpenCode 2 compatibility, wave 2: the V1 hook handlers now run on the OpenCode 2 extension points.** `chat.headers`, the system, messages and params transforms, `chat.message` with command interception, `tool.execute.before` and `tool.execute.after`, and compaction and idle continuation all fire on OpenCode 2.4.x hosts, and OpenCode 2 events are translated into the V1 event shapes by snapshot diff. The parity ledger lands its wave-2 rows (`LANDED_WAVES` is 2), with a hermetic row keeping the new CI workflow equal to `ci.yml` and to the single host version pin. ([#3](https://github.com/snoad/oh-my-openagent/pull/3))
- **QA for the OpenCode 2 port:** the `opencode-qa` skill gains a live parity runner with one strict check per row, a sandbox driver, a V1 regression script and a self-test, and a new CI workflow named `OpenCode 2 parity` runs the live driver on Linux and uploads the evidence. Knip treats the live runner as an entry, and two dead exports were removed. ([#3](https://github.com/snoad/oh-my-openagent/pull/3))

### Fixed

- On the real OpenCode 2.4.1 host, a V1 guard that vetoes a call through `output.message` now blocks there too (the bash file read guard, for example), read tool results keep their hashline `LINE#` tags, and the event translator prints its `[opencode-v2] event stats` line when a runtime stops. ([#3](https://github.com/snoad/oh-my-openagent/pull/3))
