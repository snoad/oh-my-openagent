### Added

- **OpenCode 2 compatibility, wave 3: the plugin's own agents, tools, MCP servers, commands, skills, permissions, provider and model contributions and the todo contract now register on OpenCode 2 hosts.** The V1 config pipeline runs over a snapshot of the pristine host state and its result is diffed into a registration plan, with a debounced recompute following host config changes; agents, plugin tools, the three MCP tiers, commands and skills, permissions, provider and model contributions, and the todo tools and store are all covered, and the todo contract is provided when the host has none of its own. Agent prompts are byte-equal to what V1 produces for the same configuration, before and after a host config change. The parity ledger lands its wave-3 rows (`LANDED_WAVES` is 3). ([#4](https://github.com/snoad/oh-my-openagent/pull/4))
- **QA for the OpenCode 2 registration work:** the `opencode-qa` skill's live parity runner gains rows for agents, tools, MCP, commands and MCP secret non-disclosure, each runnable with PASS and FAIL stub cases; the V1 agent baseline was recaptured under the live sandbox's model universe, and the V1 baseline capture and the V1 regression now share one sandbox config. ([#4](https://github.com/snoad/oh-my-openagent/pull/4))

### Fixed

- An absent optional skill root (a fresh install lacks every default one) no longer logs a `[skill-load]` load-error line and no longer shows the load-error toast on every startup; real skill directory errors and configured-source misses still report. ([#4](https://github.com/snoad/oh-my-openagent/pull/4))
- On the real OpenCode 2.4.1 host, added plugin tools are exposed to the model as direct tools and a tool result reaches the model as text, omo agents keep V1's "unlisted tools are allowed" behavior (OpenCode 2 asks by default, which rejected the read tool in non-interactive runs), the hashline tags on read results work again, and a single throwing registration step can no longer disable the whole plugin. ([#4](https://github.com/snoad/oh-my-openagent/pull/4))

### Known limitations

- OpenCode 2 reserves the tool name `edit`, so the hashline `edit` tool cannot be registered under its V1 name there (recorded as LIM-22; nothing replaces it in this release). ([#4](https://github.com/snoad/oh-my-openagent/pull/4))
